# 拡張時の設計と運用上の検証課題

## 対局基盤の拡張

対局の分割配置を導入する際は、処理権の期限管理と古い処理権の排除、対局ごとの接続先の振り分けを設計する。
マッチメイキングの負荷検証と履歴削除は[拡張時の制約](matchmaking.md)を参照する。

## 運用上の検証課題

リアルタイムゲートウェイの接続数、メッセージ容量、キュー件数の上限は、性能測定に基づく値ではなく、資源保護のための初期値である。
本番導入に向け、性能と本番環境のネットワーク分離、TLS 終端、プロキシ設定を検証する。

自動テストは、実際の Google アカウントによるログインの継続的な可用性を保証しない。
実際のログインの確認手順は [user-server の検証手順](../../apps/user-server/README.md#動作を検証する)を参照する。
